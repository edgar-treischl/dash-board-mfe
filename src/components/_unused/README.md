# Unused Components

This folder contains components that are no longer imported or used anywhere in the application. They can be safely deleted.

## Contents

- **TextBox.tsx** - Text box component (unused since redesign)
- **RegierungsMap.tsx** - Alternative Regierungsbezirke map (superseded by RegierungsMapSVG.tsx)
- **RegierungsMapLeaflet.tsx** - Leaflet-based Regierungsbezirke map (not used, RegierungsMapSVG is preferred)
- **RegionSelect.tsx** - Region select control (exported from controls but never imported)
- **controls/SelectIcon.tsx** - Select icon component in controls folder (unused)
- **icons/SelectIcon.tsx** - Select icon component in icons folder (duplicate, both unused)

## To Clean Up

Simply delete this folder when ready, or remove individual files as needed.
